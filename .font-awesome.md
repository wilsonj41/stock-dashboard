# Font Awesome Configuration

Verified using the fallback script and the Kit's publicly loaded bundle. Commit this file for future icon work.

## Integration
- **Method:** Kit embed (SVG+JS)
- **Version:** 7.3.1
- **License:** Free
- **Kit ID:** 618af56931
- **CDN URL:** https://kit.fontawesome.com/618af56931.js
- **Families:** Classic (Free Solid, Regular, Brands)

## Defaults
- **Style:** solid
- **Family:** classic

## Import Pattern
The script in index.html loads free.min.js. Use class-based icons inside a React-owned wrapper; no npm imports.

## Conventions
Decorative icons have aria-hidden. Controls have visible labels or aria-label. The public Kit config has no subsetPath; requested icon names were checked in its free.min.js bundle using the user-authorized fallback. No CLI required for this verification.
